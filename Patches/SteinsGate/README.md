# STEINS;GATE localization modules

Game-specific STEINS;GATE fan-localization projects are stored as siblings under this directory.

User-facing documentation refers to each complete localization project as a **module / 模組**. The existing `Patches/` path and technical patch terminology remain unchanged for repository and implementation compatibility.
